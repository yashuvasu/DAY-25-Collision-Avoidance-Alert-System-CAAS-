# 🚗 Day 25 – Collision Avoidance Alert System (CAAS)

## 📌 Overview
This project simulates a basic Collision Avoidance Alert System using C programming.

It calculates the **Time to Collision (TTC)** based on:
- Distance to object
- Relative speed

And provides real-time alerts to the driver.

---

## ⚙️ Features
- Distance monitoring
- Relative speed calculation
- Time to Collision (TTC)
- Risk level detection
- Real-time alert system

---

## 🧠 How It Works
1. Takes distance and relative speed as input
2. Converts speed into m/s
3. Calculates TTC
4. Determines risk level:
   - SAFE
   - WARNING
   - HIGH RISK
5. Displays alert

## 💻 Technologies Used
- C Programming
- GCC Compiler
- Ubuntu/Linux
